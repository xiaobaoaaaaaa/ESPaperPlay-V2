# r11：r10 首批制板、备料与装配准备

2026-11-14。本轮是准备记录 **r11**，PCB 保持 **r10**，没有产生新的 PCB 版本。用户确认 **5 块裸板、先焊 2 块、无框钢网配胶带铰链手工定位**。原生 PCB、11 页原理图、工程库、r10 裸板/钢网包和固件均保持。

## 已落实的准备

1. [加工审核要求](../../../hardware/devboard-r0/output/manufacturing/r10-first-batch/production-request.txt)已写成可直接提交的文本：5 片 160×110mm 四层板、1 张完整 280×380×0.10mm 无框电解抛光钢片，附准确文件 SHA-256、四行阻抗表、11 孔工艺与生产稿回复项。仅整理本地文件，尚未向工厂提交。
2. [备料表](../../../hardware/devboard-r0/output/manufacturing/r10-first-batch/procurement-plan.html)按厂商、完整料号和封装合并为 **64 种候选物料**。两板净需 **460 件**：406 位回流、54 位手焊；6 个 DNP 位号不采购、不装配。按公开的可调整规则另列198件可选备料，合计658件，不含跳帽、外接件或仪器。库存、MOQ、价格均未知，不把备料量称为净采购量。
3. [关键电容审查](../../../hardware/devboard-r0/review-r11/component-closure.md)核对56个实装电容、10种料号与实际网络；没有新增必须换料/改封装的证据。C102/C103/C201/C202 的偏压后门槛分别为4.7/4.7/4.0/7.0µF，继续按离板来料或厂家数据闭合；仍未取得联合偏压/温度/老化保证，不把候选BOM标为冻结。
4. [首板工作单](../../../hardware/devboard-r0/review-r11/first-board-checklist.md)由当前网表核对端子针号、测流点、跳帽与分域顺序。两板测量模板各13项，全部待测。先验证第一块的印膏、回流、手焊和默认状态，再装第二块作为对照。

## 本轮新增的具体注意事项

国内阻抗说明与此前国际计算器使用的外层铜厚/阻焊模型口径不同。r10名义窗口结论保留；实际订单须明确 **USB90Ω±10%、SD50Ω±10%**，回复真实层叠与补偿。不能把“无要求/±20%”当成同等阻抗控制。钢网厂默认可能重新处理焊盘，须明确 **只用专用单层Gerber，按现有膏口1:1，不增MARK孔，不按板框裁掉钢片余边，先确认最终加工稿**。来源和实际页面核对见[工厂审查](../../../hardware/devboard-r0/review-r11/factory-capability-review.md)。

J101的5V输入仍经过BQ默认100mA档，无电池时不能保证MCU冷启动。首板工作单先检查输入空载，再使用J102单源限流3.7V模拟电池，真实电池/J101断开、J502拔除，R108 DNP、J105开放。不能把普通台架当作可吸收充电电流的电池模拟器。所有电流设置均是工程起始值，不是器件保证。

现有M0固件不初始化新板外设。完整分域验收前仍需专用维护固件，工作单给出GPIO与TCA9539安全初始化契约；本轮没有把文档步骤当成已实现功能，也未烧录。
