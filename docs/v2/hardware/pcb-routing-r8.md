# 开发验证板 PCB 布线 r8

日期：2026-11-07。基于 [r7 器件布局](pcb-layout-r7.md)，继续使用 160 × 110 mm 四层开发板。原理图、电气网络、候选 BOM 和 6 个 DNP 位置保持；本次工作仅完成 PCB 布线、必要的局部位置调整、铺铜及静态检查。

正式入口：[KiCad PCB](../../../hardware/devboard-r0/ESPaperPlay_Devboard.kicad_pcb)、[工程](../../../hardware/devboard-r0/ESPaperPlay_Devboard.kicad_pro)、[审查记录](../../../hardware/devboard-r0/review-r8/README.md)。

## 层叠与走线

采用 JLC04161H-7628 的名义四层 1.6 mm 层叠：F.Cu / In1.GND / In2.GND / B.Cu，元件全部在正面，两个内层保持连续地平面，信号与电源只走外层。外层铜厚按 35 µm、内层按 15.2 µm；两侧 PP 各 0.2104 mm，芯板 1.065 mm。完整参数及来源见 [阻抗估算](../../../hardware/devboard-r0/review-r8/stackup-impedance.json)。

| 类别 | 实施方式 |
| --- | --- |
| 普通信号 | 标称 0.20 mm；密集引脚处允许短 0.15 mm 颈线；默认铜间距 0.15 mm |
| 电源 | 主干 0.8 mm，局部加强至 1.0/1.2 mm；各外设按电流及可布空间单独审核 |
| USB | 主长差分对 0.26 mm 线宽 / 0.15 mm 边间距；两种 Type-C 接触路径分别检查匹配 |
| SD | 主线 0.35 mm，细脚短颈单独统计；按实际连通路径检查长度及调试分支 |
| 过孔 | 普通 0.6/0.3 mm；密集区及接地回流 0.45/0.2 mm，均为通孔 |
| 接地 | 两层铺地，去耦局部落地、信号换层邻近回流孔；天线和麦克风原封装禁布区保留 |

USB 90 Ω 和 SD 50 Ω 是设计目标。当前闭式公式的名义估算分别约 89.96 Ω、49.98 Ω，尚未取得工厂场求解器和成品测试确认；阻焊、铜截面、细颈、焊盘及开关器件均会改变局部阻抗。设计依据为 [Espressif 布局指南](https://docs.espressif.com/projects/esp-hardware-design-guidelines/en/latest/esp32s3/pcb-layout-design.html) 和 [JLC 层叠资料](https://jlcpcb.com/impedance)。

## 关键电路处理

充电器、升降压转换器、电量计、各路负载开关、电子纸外部升压回路及功放去耦先做局部布线，再完成普通信号。R602 的检测回路从电阻焊盘单独引出；电池主电流绕开电量计 C204 取样节点。主控供电绕行和屏幕输入长细线已局部优化。

电源检查使用原生 KiCad 连通关系追踪铜路径，按 35 µm 铜厚、20 µm 孔壁镀铜及 20/85°C 估算电阻。它不包含连接器、保险丝、测流电阻、器件导通阻抗，也不能替代温升和瞬态测试。SYS 和功放个别短颈超过内部长度审查目标，保留原始检查提示，并在 [电源审查](../../../hardware/devboard-r0/review-r8/power-routing-review.md) 中列出长度、压降和接受条件；没有通过修改检查阈值隐藏提示。

## 验证边界及下一阶段

- 布线交付的连通、间距、原理图一致性及冻结身份检查，见同目录审查记录中的最终报告；历史 r7 仍保留为布局阶段记录。
- 充电器、升降压、功放等器件存在焊盘内散热过孔。贴装前须与板厂确认填孔、封帽和焊膏方案，不能把普通盖油当成防吸锡工艺确认。
- R108 继续 DNP，初装仍禁充。用户授权的 NTC 曲线假设和约 0.7 A 充电电路不变；电池温窗匹配、充电计时和散热由样机验证。
- USB/SD 信号完整性、无线发射下供电瞬态、电子纸高压和电流峰值、音频噪声、深睡漏电、FPC/线束方向及实物装配仍需样机检查。静态 DRC 通过不等同于这些性能已验证。
- 本次不下单、不采购、不生成制造发布包。下一阶段为制造工艺及装配检查，然后进行受限电源下的分域上电验证。
