# 开发验证板充电与温控电路 r5

日期：2026-11-04。用户授权按检索到的 Honeywell 175-103LAE-301 Rev.B 阻温表先设计，并提高充电电流。本轮已修改原生 KiCad 电路，新增第11页 `CHARGE_TEMP`。**当前是可继续布局的设计候选；没有实物充电、PCB/DRC或制造验证。**

打开[KiCad工程](../../../hardware/devboard-r0/ESPaperPlay_Devboard.kicad_pro)，或查看[十一页原理图PDF](../../../hardware/devboard-r0/output/pdf/ESPaperPlay_Devboard_Charging_r5.pdf)。[r5 BOM](../../../hardware/devboard-r0/review-r5/bom-review.json)含236个位置、6个DNP，全部有封装候选；C501/C502两个USB调谐DNP仍不指定料号。r4的PDF、工作簿和审查报告保留为历史，不代表这次新值。

## 充电电流与终止

| 项目 | r5电路 | 计算最小／典型／最大 |
| --- | --- | --- |
| R104 / ISET | 1.27kΩ，1%，CRCW06031K27FKEA | 0.617／0.701／0.781A |
| 新增R113 / ITERM | 1.27kΩ，同型号；U101.15到GND | USB500/ILIM：21.77／30／38.76mA |
| USB100终止电流 | 同一R113 | 7.74／10／12.40mA |
| R105 / 快充计时 | 保留68kΩ | 6.688／9.067／11.521h |
| R103 / 输入电阻限流档 | 保留1.62kΩ | 0.911／0.994／1.079A |

选择约0.7A，可在电阻温漂及芯片系数预算下将上界控制在0.8A以内，符合中顺芯系列资料对低于20°C时0.2C的限制。加入ITERM电阻，将普通档终止电流上界控制在4Ah的1%即40mA以内；原来悬空ITERM的默认比例在提高电流后约为70mA，故本轮一起调整。电池官网是系列依据，实际755570电芯的CV容差和保护条件仍须样机核对。[官网资料记录](battery-zoncell-2026-11-04.md)

电阻模型包括1%初差、100ppm/K和本体−40…85°C；BQ系数按手册规定的结温条件使用。计时保留在允许18–72kΩ内，接受首版超时停止、可能未充满，不通过循环CE或输入重插自动续时。完整公式、系数和断言见[充电计算](../../../hardware/devboard-r0/review-r5/power/charge-bounds.json)及[脚本](../../../hardware/devboard-r0/review-r5/power/calculate_bounds.py)。[TI BQ24074资料](https://www.ti.com/lit/ds/symlink/bq24074.pdf)

默认输入仍为USB100。0.7A目标用于已知5V供电、输入档位配置正确且系统轻载的情况；最小输入限流减最大充电电流只余约130mA供系统及芯片。Wi-Fi、音频和刷新并发时允许DPPM降低充电电流。线性充电器在5V输入、3V电池及100mA系统负载算例约耗散1.63W，5.25V/2.9V压力算例约1.93W；PCB须布散热铜与过孔，不能承诺全程维持0.7A。此前整机电池总放电1A预算不因此改变。

## 独立温窗

真实电池NTC经J103接入 `BAT_NTC`。新U901 **TLV1822DR**由与BQ相同的 `VIN_5V` 供电，比较冷热阈值；两路开漏输出并到 `CHG_TS`，连接BQ的TS脚。温度越界时拉低TS，充电器暂停充电并保留计时值；无需MCU执行温控，也不会因温度边界反复切换CE而重新计时。

| 位号 | 连接与标称值 |
| --- | --- |
| R901 | VIN→BAT_NTC，47kΩ |
| R902/R903 | 热参考上/下分压，100kΩ/12kΩ |
| R904/R905 | 冷参考上/下分压，100kΩ/33kΩ |
| R906 | CHG_TS→GND，10kΩ |
| R907/R908 | CHG_TS→BAT_NTC / 冷参考，各330kΩ正反馈 |
| C901 | U901电源100nF旁路 |
| C902/C903/C904 | NTC、热参考、冷参考各10nF C0G滤波 |

R906是外部温控接口的偏置电阻，实际温度仍由J103的NTC决定。它不等于用固定电阻取消测温。两条反馈互相耦合，计算联立NTC、冷参考、TS三节点；不能分别套用两个独立比较器公式。

按假设的Honeywell完整阻温表，5V标称模型冷端约 **14.8°C暂停**、热端约 **40.1°C暂停**。以故障输出0.1V作恢复示例，分别约15.5°C、39.5°C；0.1V仅为演示点，并非器件典型保证值。

在5V±5%、电阻误差/温漂、NTC min/max曲线和比较器误差预算内，冷暂停12.39–17.12°C、热暂停37.25–43.10°C；同角点滞回为正。计算支持10–45°C范围内留有余量，**前提是实物符合所假定曲线和比较器预算**。详细[温窗分析](../../../hardware/devboard-r0/review-r5/temperature/review.md)和[机器结果](../../../hardware/devboard-r0/review-r5/temperature/temperature-window-results.json)记录了模型边界。

NTC开路产生冷故障，短路产生热故障，均拉低TS。U901输出低电平预算0.25V，BQ最低热阈值0.27V，纸面余量20mV；TI的相关电气表测试条件为12V，当前5V下失调/低电平采用工程预算，须实测确认。共用VIN可覆盖正常输入消失，不声称覆盖U901独立供电断线或任意器件失效。POR及TS去抖仅有典型时序，本轮未声称启动瞬间无充电脉冲。[TI TLV1822资料](https://www.ti.com/lit/ds/symlink/tlv1822.pdf)

R108继续DNP、J105默认开路。J105维护使能只控制CE，不旁路新温窗。BQ在TS故障暂停时CHG_N仍可能保持低，因此**验收须测电池充电电流和TS，不能只看充电指示**。本轮没有新增温度ADC或修改固件。

- 原生工程11页，236个器件位置、181条网络；ERC为0错误、0警告、0排除。
- 原检查链668项关键连接通过；新增独立r5检查覆盖全部774个引脚连接，精确限制旧电路允许变化。222个原器件UUID、DNP和未声明的旧连接均保留。

正式记录在[verification.json](../../../hardware/devboard-r0/verification.json)。本轮可继续PCB预布局；BQ散热、NTC线远离开关节点、模拟参考共地、输入与电池线束走向应在布局中落实。
