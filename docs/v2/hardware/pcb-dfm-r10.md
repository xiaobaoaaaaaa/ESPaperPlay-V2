# r10：近焊盘过孔整改与制造规格

2026-11-14。承接[r9制造审查](manufacturing-review-r9.md)，本次实际修改PCB，闭合近焊盘过孔的几何问题，并选定热孔处理工艺。正式板为r10，原理图仍为r6绘图/r5电气；器件、网络、接口方向及充电默认状态保持。源文件版本与哈希见[设计基线](../../../hardware/devboard-r0/review-r10/design-baseline.json)。

## 已实施的修改

对全部549个原生过孔检查两面实际Gerber阻焊开口，发现原表44孔之外还有20孔低于本项目0.20mm目标。移动64个孔（62 GND、PGOOD_N和SD_CARD_D0各1），调整67条原有相连线段的端点，保留所有UUID；没有增加或删除线路/过孔，没有移动器件。

R213.2/R214.2的接地孔改为板上已有的外径0.45/钻孔0.20mm规格，其余孔径不变。当前207孔为0.45/0.20、342孔为0.60/0.30；11个IC热孔和U301自带12个孔保留。板框仍160×110mm、四层1.6mm，2335条线路、549个原生过孔。

整改后，排除明确保留的11个IC热孔，**全部538个普通过孔的孔边到两面阻焊开口均不小于0.20mm**；原先最小约0.005mm的近孔情况已消除。这是项目设计间距，不能当作钻偏、阻焊对位和成品可靠性的保证。数据来自实际Gerber开窗与原生孔的逐孔比较，见[全孔登记表](../../../hardware/devboard-r0/review-r10/all-via-mask-clearance.csv)。

## 阻焊保持现状，纠正r9的一处判断

嘉立创[现行能力说明](https://www.jlc.com/portal/vtechnology.html)支持新板LDI按焊盘与阻焊开窗1:1制作，**零扩展本身不是制造缺陷**。本次保持原阻焊几何，通过移孔获得空间，没有全板扩大开窗。

既有局部扩展也完整保留：53个编号SMD焊盘为+0.05mm，7个U803焊盘为+0.025mm，其余637个为0。+0.05mm包含U101/U201、Q101/Q201、L201、F501和8个测流跳线，并非r9概述中的“只有U101/U201”。当前最窄异网阻焊间隙0.150mm；把所有零扩展焊盘改为+0.05mm反而会将U802部分桥宽降至约0.0768mm。完整测量和依据见[阻焊与热孔工艺说明](../../../hardware/devboard-r0/review-r10/mask-and-thermal-process-r10.md)。

生产稿应保留这些指定的局部开窗，不能未经复核一律缩为1:1或全板扩大。

## 11个热孔采用明确工艺

U101×4、U201×2、U203×1、U802×4，共11个Ø0.20mm孔，指定**树脂填充、平整化、电镀铜盖帽≥10µm、可焊ENIG表面**。保持孔铜、热焊盘、接地和原钢网分窗；不能用普通盖油或覆盖热焊盘代替。准确UUID、绝对坐标和孔径见[11孔工艺清单](../../../hardware/devboard-r0/review-r10/thermal-via-fill-spec.csv)。

11孔是设计所需的最小范围，不代表已确认板厂支持仅处理或仅收费11孔。若实际工艺要求扩大到全部过孔，须在生产稿列明范围；95个普通组件镀孔和7个NPTH必须畅通，尤其Ø0.60mm麦克风声孔。U301中心EPAD仍不印膏，其12孔不新增强制填孔要求。

## USB/SD与其余电气条件

官方计算器四点窗口已补齐：指定JLC04161H-7628、带阻焊非共面模型下，SD的45–55Ω对应线宽0.4295–0.2951mm；USB的81–99Ω对应0.3195–0.1897mm，输入间距0.1500mm、输出显示0.1501mm。现有SD 0.35mm、USB 0.26/0.15mm处于窗口内，本次保持线宽。

这闭合了官方**名义模型窗口检查**，不是工厂成品阻抗保证，也没有把现几何反求成一个新的精确Ω值。仍在加工要求中指定USB 90Ω±10%、SD 50Ω±10%、F.Cu参考In1、B.Cu参考In2。详见[计算记录](../../../hardware/devboard-r0/review-r10/impedance-review-r10.md)。

SD D0主路径缩短约0.056455mm，调试支路不变；其他五路SD及全部USB路径不变。SD最大CLK长度偏差仍0.806237mm。既有D0/D1调试支路19.213/13.546mm及2–4次转层的实测边界继续保留，未宣称信号完整性认证。

全量核对219个非GND via的最近接地via距离，没有新增跨越内部2mm目标的情况。EPD_EN为1.819750mm、3V3_AON为1.943456mm；既有IOX_RESET_N 2.146407mm和USB_DP_PORT 2.289651mm保留，几何距离仍不能替代回流阻抗/实测。
