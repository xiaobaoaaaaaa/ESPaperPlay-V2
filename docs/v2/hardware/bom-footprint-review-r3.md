## 已落图的主要结果

- **主控保持 ESP32-S3-WROOM-1-N16R8。** 模组外围焊盘对应关系已核，中心接地焊盘的铜、过孔和钢网仍按贴装工艺复核；天线净空要落实到未来 PCB 与外壳。
- **TPS63802DLAR 使用专用 DLA0010A 封装。** 这是非对称的 10 个编号焊盘，8 脚 PGND 为加长焊盘，不能再另加一个中心 EP。BQ24074RGTR 同步采用原厂 RGT0016C 推荐 land，EP 为 1.68×1.68 mm。
- **MAX98357AETE+T 明确追溯至 T1633+4 / 90-0031。** 专用封装采用 0.8×0.3 mm 周边焊盘、0.5 mm 节距、1.23×1.23 mm EP。旧通用库引用 +5 / 90-0032；旧 EP 1.23 mm 和编号本身并没有错，本轮解决的是准确封装版本与推荐焊盘来源。
- **TPD2E2U06DCKR、MF-MSMF110/16X-2、AO3400A 和电源测流跳线采用对应原厂几何。** 分别建立 DCK0003A、1812 Style 2、AOS PO-00001 N 和 Bourns CRF0805 金属跳线封装，保留各自真实脚序及载流约束。Coilcraft XFL4015-471MEC 和五种开发板排针也建立本地候选；铜线、焊点、线束和实际温升仍独立限制可用电流。
- **100 nF 候选采用 TDK C1608X7R1H104K080AA。** 规格为 50 V、X7R、±10%、0603；检查日原厂标为 Production。原 Murata GRM188R71C104KA01 被原厂标为 *To be discontinued*，未选入新版候选。
- **EPD 整流二极管采用 onsemi MBR0530T1G。** 旧 MBR0530 为 Last Shipments；新型号的 Active 状态、独立 T1 数据表、30 V / 0.5 A、Vf 最大 0.43 V@0.5 A/25°C、SOD-123 的 1K/2A 已分别核验。没有因名称相近就假定跨厂或跨版本等效。
- **EPD 电感候选为 Bourns SRN4018-100M。** 10 µH±20%，Irms 1.3 A 对应温升 40°C，Isat 1.4 A 对应电感量下降 30%；这些定义不能替代启动、刷屏峰值与温升验证。六颗 4.7 µF / 50 V 改用 Murata GRM31CR71H475KA12L 的 1206 候选，但仍未证明工作偏压下的最低有效容量。
- **USB 接口采用 GCT USB4105-GF-A 候选。** 原厂图与库中的共享电源/GND 焊盘、独立数据焊盘、定位孔和外壳固定脚已核。microSD 继续保留 Hirose DM3AT-SF-PEJM5 候选；实际为 push-push 结构，完整机械禁布区和样品适配尚未放行。

分项证据见 [电源审查](../../../hardware/devboard-r0/review-r3/power/review.json)、[EPD/音频审查](../../../hardware/devboard-r0/review-r3/audio_epd/review.json)、[接口审查](../../../hardware/devboard-r0/review-r3/interconnect/review.json) 和 [通用器件审查](../../../hardware/devboard-r0/review-r3/root/review.json)。原厂状态是检查日观察，未查询或保证未来库存、价格和交期。

## 仍保留空白的 7 个封装

| 位号 | 保留空白的原因与闭合条件 |
| --- | --- |
| J102 | 电池包连接器、极性和线束额定未定；需与所选带保护单节电池一致。 |
| J103 | NTC 接口、线束及电池 NTC 曲线/温区未定；不能用通用排针代替最终定义。 |
| J406 | 触摸 FPC 的接触面、插入/加强板长度和折叠方向未闭合；优先核旧件 **LAIL-FPC-CDX01-6P0.5-GW** 的原厂图或实物。 |
| J601 | 屏幕 FPC 的接触面、端部尺寸、固定结构与插座适配未闭合；优先核旧件 **HYCW3D-05FPC24-200B**，不凭 24 位 / 0.5 mm 就替成 FH12。 |
| R602 | 0.47 Ω / 1% 只定义阻值；须确定峰值、RMS、脉宽、占空比与温度降额后选择脉冲额定和封装，并落实 Kelvin 采样。 |
| J801 | 8 Ω 扬声器及线束连接器未定；BTL 两根输出线均不能接地。 |
| U803 | PUI 七焊盘结构已核，但 PCB 声孔、声道、阻焊和焊膏开窗未定；器件声孔 Ø0.25±0.05 mm 不是 PCB 钻孔规格。 |

屏幕与触摸必须分别核对正反面和 1 脚方向：现有总成 CAD 的两条 FPC 正视编号方向并不相同。FH12 只作为尺寸比较对象，屏幕端部尺寸与其要求存在需解释的差异；旧件记录见 [显示与触摸旧板审查](review/legacy-display-touch.md)。麦克风还需确认生命周期和可采购性，不能把公开产品页等同于供货承诺。

## 电流与工艺约束

**F501 的 1.10 A 保持电流仅适用于 23°C，50°C 降为 0.85 A。** R103=1.62 kΩ±1% 在可编程高档对应输入限流约 0.917–1.072 A；0.85 A 已低于该高档区间下边界，因此高温下需要重新闭合保险丝、充电加系统负载与输入电流预算。这个比较针对可选高档，**默认输入档仍是 100 mA**，不能将高档能力当成默认工作状态或 USB 来源授权；也不能直接换大保险丝来绕过预算问题。

**充电仍默认禁止，R108 继续 DNP。** 当前 ISET 的约 0.297 A 典型值只是设计候选，电池容量、允许充电电流、保护和 NTC 条件未闭合前不启充。输入档位规则沿用 [电源设计规格](power-design-spec.md)。

Q601 的指定 Vishay Si1308EDL-T1-GE3 脚序为 1G/2S/3D。当前通用 SC-70 焊盘短边 0.45 mm，小于 Vishay AN826 推荐最小 0.559 mm，贴装前须决定保留经工艺认可的通用 land，还是建立专用 land；此项没有被本轮“封装已指定”状态消除。

其余通用 TSSOP/SOT 封装与原厂示例也可能存在 IPC land 差异，脚数、脚序及壳体匹配不等于钢网和焊点工艺已验证。QFN/DFN 的焊膏覆盖、散热过孔和铜面积，模组中心焊盘，以及按键低电流接触可靠性仍需后续检查。

## 下一步

先闭合 J601/J406 的实际 FPC 插接、J102/J103 的电池与 NTC 接口、J801 扬声器线束以及 U803 声孔结构，完成可用于布局的机械接口表。并行建立逐轨电压和最坏负载预算，取得 MLCC 偏压曲线，确定 R602 脉冲额定、输入保险丝高温保持电流和两颗电感的实际裕量。
