# 开发验证板 PCB 布局 r7

日期：2026-11-06。用户确认采用独立开发验证板，尺寸由设计确定；屏幕、电池、扬声器外接。原生 PCB 位于 [ESPaperPlay_Devboard.kicad_pcb](../../../hardware/devboard-r0/ESPaperPlay_Devboard.kicad_pcb)，同名 KiCad 工程可直接打开。

本轮完成器件布局、板框、机械孔、接口方向、禁布区域和主要操作标识。**布线、地铜、散热过孔和阻抗实现属于下一阶段；本板尚不能制造使用。** 原理图仍为 r6 绘图，电气设计仍为 r5，未改元件值、网络、DNP 或候选料号。

## 板形与分区

| 项目 | 当前布局 |
| --- | --- |
| 板框 | 160 × 110 mm，坐标 x=50–210、y=50–160 mm |

| 名义叠层 | 铜层各35µm；介质0.20 / 1.06 / 0.20mm；FR4参数仅供工程占位，尚未选定制造商叠层 |
| 安装孔 | 四个Ø3.2 mm NPTH，距相邻板边5 mm；机械位号H1–H4，排除电气BOM |

| USB | 上边缘，ESD靠插座，22Ω串阻与DNP调谐位置靠MCU |
| 音频 | 左上区，扬声器端子朝上；麦克风靠左，远离功放输出与两组电感 |
| SD / 触摸 | 右侧开口，保留取卡、排线与锁扣操作空间；SD六线开关靠主控与卡座之间 |

布线用途约定：F.Cu放关键短回路和信号；In1.Cu留连续地参考；In2.Cu安排电源与地；B.Cu承载必要的辅助信号。USB、SD途经区域须保持连续参考地，不用分割地平面隔离模拟/数字区域。

## 已落实到位置的约束

- U101的输入、系统输出、电池旁路分别紧邻对应引脚，芯片散热焊盘未被其他器件占据；R108仍DNP、J105默认开放。
- U201的输入/输出电容在VIN/VOUT侧，电感在L1/L2侧，反馈分压在FB侧；R203位于稳压核心之外，反馈仍从测流连接之前取样。
- 每个TPS22918的输入电容、CT电容、输出电容与测流跳线围绕其本体布置。
- NTC接口、分压滤波、比较器集中在安静区域；与主稳压、EPD电感分离。
- EPD缓冲串阻靠输出脚；Q601/L601/R602及电荷泵靠面板；R602到J601.3的Kelvin取样走线在下一阶段落实。
- 音频去耦靠功放/麦克风电源脚；BTL两根扬声器输出成对引出，均不接地。U803的原生Ø0.60mm非金属声孔和全铜层禁布保留。
- SD卡座原有五块F.Cu规则区保留；卡弹出、FPC开锁区域画在Dwgs.User，板外线束不能进入天线净空。
- 密集区域优先保留器件间距和短回路。参考标号按实际空隙排布；无法合理放丝印的少量标号保留在F.Fab装配层。

## 检查的含义

236个电气位号、181条网络、774个逻辑引脚与原理图逐项匹配；带重复编号焊盘的封装逐个检查，合计804个实际编号焊盘。四个机械孔单独统计。38种封装的焊盘、钻孔与原库规则区由独立检查器核对，符号到封装的UUID路径和候选属性保留。

KiCad DRC保持未连接检查开启：499个未连接项、0个原理图一致性问题，未发现短路、间距、器件占位重叠或丝印违规。未布线项是当前阶段真实状态，不设排除。U301保留一条库封装差异警告：其伸到板外的天线丝印线移到Dwgs.User，避免要求在板外印刷；焊盘、天线禁布与原库相同。这是明确的绘图差异，不是引脚或铜几何差异。

独立检查器另记录C301大容量旁路的焊盘距离5.305mm，稍超过内部5mm审查目标；本布局接受该位置，100nF高频去耦C302到模块电源焊盘为1.875mm。后续保证电源短宽连接和就近地过孔。SD六线经过调试排针的几何距离估计为35.6–46.3mm，实际绕障与过孔可能增加长度，须在布线阶段重新检查。

## 继续布线时的顺序

1. 选定实际四层工艺与叠层，再确定USB 90Ω差分、SD约50Ω单端所需线宽/间距。当前项目默认线宽和间距不是阻抗计算结果。
2. 先完成BQ散热地、TPS63802输入/电感/输出短回路，再处理EPD热点、采样Kelvin线及高压储能；避免开关节点铜岛过大。
3. 布USB和SD主干；调试排针按主干经过或尽可能短的分支处理，避免以DNP作为忽略信号支线的理由。
4. 完成音频、触摸、NTC和控制信号，铺地、添加回流/散热过孔，核对板底声孔及所有层禁布。
5. 检查未连接、短路、间距、阻焊、孔铜距离、丝印和原理图一致性，再检查制造文件；实物功耗、充电、温度和信号完整性仍需样机验证。

原生PCB是后续编辑源。本轮临时坐标和脚本保存在迁移前的本机旧工作目录 `build/pcb-r7/`，未纳入独立仓库，不能在手工布线后用它们覆盖PCB。r6源文件快照保存在该旧目录的 `intake/`；独立仓库正式保留上一版校验清单与本轮位置清单。
