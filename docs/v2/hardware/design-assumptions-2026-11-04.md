# 开发板设计假设补充：电池与纯延长连接

日期：2026-11-04，更新至r5充电设计。用户要求电池按保守值推进，并明确屏幕、触摸的转接件仅用于延长、无其他功能，以原厂文档为准；随后授权按检索到的NTC候选曲线设计电路并提高充电电流。本页与[r5充电设计](charging-design-r5.md)共同定义当前候选；r4审查快照保留为历史证据，充电连接及参数以r5为准。

同日[中顺芯官网核查](battery-zoncell-2026-11-04.md)取得三线NTC系列的4.2V、0.1C标准/0.2C快速充电和10–45°C温区依据。用户同意采用Honeywell **175-103LAE-301 Rev.B**曲线作为设计假设；**尚未证实该型号就是755570电池内实际NTC**。以下续航、放电预算及默认禁充状态不变；r5采用独立硬件温窗，并把4Ah×0.2C=0.8A作为充电设定的设计上限。

## 电池：用保守预算推进开发

| 项目 | 本阶段采用的值 | 含义 |
| --- | --- | --- |
| 电池体系 | 1S、标称3.7V，按4.2V充电体系进行设计 | 延续已选方案的设计假设，未把商品图片当作实物充电规格认证 |
| 标称容量 | 4000mAh | 用户选定商品参数 |
| 续航预算 | 暂用75%可用能量系数，等效3000mAh、约11.1Wh | 工程留量，不是实测容量或保证下限；包含截止、温度和老化的暂估，后续用数据替换 |
| 首轮电池测试环境 | 20–30°C | 测试时外部确认；r5已有硬件温窗候选，实物曲线、动作温度和温升仍待测，暂无低温/高温运行保证 |
| 首轮电池端负载 | 总放电电流预算≤1.0A，暂不给短峰值额外余量 | 包括各电源域和转换损耗；不引用商品3A无时长脉冲能力。是待验证的负载包络，不是硬件限流设定 |
| 充电电流候选 | R104=1.27kΩ，典型约0.701A，约0.175C | 在规定电阻温漂及TI系数范围下约0.617–0.781A；最坏设定低于0.8A设计上限，输入/热限制可能降低实流 |
| 终止电流候选 | R113=1.27kΩ接ITERM，普通输入模式典型30mA | USB500/ILIM下计算约21.77–38.76mA，低于4Ah×0.01C=40mA；USB100计算约7.74–12.40mA |
| 初装充电状态 | R108 DNP，J105保持开放 | 假设允许推进布局；实际启充前确认电芯CV、温度检测和充电参数匹配，维护跳线也不绕过温控 |

可用容量折减只用于续航估算。充电计时仍按4000mAh整包需求考虑，不能将3000mAh预算反过来当作电池实际容量以缩短安全计时。11.1Wh也不应重复扣除同一组容量损失；若负载按电池端功率实测，不能再重复扣转换效率。

为使负载预算自洽，低负载设计例采用：主3V3轨0.5A、音频电输出0.25W、SYS低端2.9V、主稳压/功放各80%效率、其他电池端电流50mA：

```text
I_BAT_est = 3.3V × 0.5A / (0.80 × 2.9V)
          + 0.25W / (0.80 × 2.9V)
          + 0.05A
          ≈ 0.869A
```

2.9V是电源路径分析假设，不是允许实物电池放电到2.9V；80%效率也不是器件保证值。该例说明分配是否合理，不保证Wi-Fi、SD写入或刷新瞬间满足1A。样机先用限流台架源测瞬态；超出1A的组合仍留在台架验证，不能仅看万用表平均值宣称通过。音量/任务错峰、欠压处理及温度采样尚未在固件实现；r5充电温窗由硬件独立执行，不依赖这些固件能力。原r4主轨1A/1.5A压力点继续作为电源设计台架目标，不再作为本阶段实物电池负载许可。

NTC候选按[归档的Honeywell曲线](../../../hardware/reference/ntc175-2026-11-04/honeywell-175-103lae-301.pdf)设计：R25=10kΩ±3%、B25/85=3750K±3%。这些是候选型号参数，不补写成实物电池事实；保护板阈值、延时和实物电芯允许CV也仍待测或核对。BQ24074固定充电电压为4.20V典型、4.23V上界，不能通过ISET降至4.1V。[TI BQ24074 Rev.N，电气表/§9.3.6](https://www.ti.com/lit/ds/symlink/bq24074.pdf)

r5第11页`CHARGE_TEMP`使用VIN_5V供电的TLV1822DR：真实`BAT_NTC`由47kΩ上拉，冷热参考分压分别为100kΩ/33kΩ、100kΩ/12kΩ；比较器1/7脚开漏输出共享`CHG_TS`，TS以10kΩ接地。`CHG_TS`分别通过330kΩ向`BAT_NTC`和`COLD_REF`正反馈，VIN去耦100nF，NTC/HOT/COLD各10nF。5V标称模型冷暂停/恢复为14.82/15.49°C，热暂停/恢复为40.05/39.49°C；恢复点以输出低电平0.1V演示，不代表器件典型VOL。全角模型结果及工程预算边界见[r5温控计算](../../../hardware/devboard-r0/review-r5/temperature/temperature-window-results.json)、[独立复核](../../../hardware/devboard-r0/review-r5/temperature/review.md)和[r5充电设计](charging-design-r5.md)，设计要求暂停边界始终落在10–45°C内。这是原理图与计算候选，尚未实测验证；TS的10kΩ用于比较器输出接口，实际温度仍由电池NTC检测。

R105=68kΩ保留典型9.07h计时，完整边界约6.688–11.521h。4Ah÷0.701A≈5.71h仅是理想容量比值；CV尾段、系统分流和热降流使其不能作为充满时间承诺，最短计时下可能未充满便超时停充。保留RTMR18–72kΩ限制，不关闭计时、不自动反复重启；温度暂停经TS执行并保持计时进度，不以反复翻转CE实现。R103=1.62kΩ输入限流不变，未知USB保持100mA。计算、电阻温度范围和热估算见[r5电源边界](../../../hardware/devboard-r0/review-r5/power/charge-bounds.json)。电池充电在样机阶段单独验证，不阻塞当前制板设计；本次没有采购或使能充电。

## 屏幕与触摸：以原厂文档定义连接

- 现有FP24/FP6组件按**无附加功能的被动延长件**处理，不新增稳压、升压、缓冲、协议转换或换序功能。
- EPD以GDEY075T7-T01规格书及总成机械图为准；触摸以TP075-Y01图纸和GT911资料为准。资料入口见[屏幕与触摸参考](panel-reference.md)。
- 原理图按屏端对应针号/同名网络延长：EPD24针，触摸6针GND/VCC/RESET/INT/SDA/SCL。连接器安装方向、接触面及封装焊盘编号由所选插座图纸配合屏端文档完成。
- 沿用r4的J601/J406封装候选及SH接地。用户已提供设计依据，转接件型号、内部功能或额外实物证明不再作为进入布局的前置要求，也不再反复向用户索取。
- 标准装配检查仍确认插入方向和无短路；这不表示本轮已经做过实物测量，也不把两端“朝左数第1根”机械等同于文档Pin1。
