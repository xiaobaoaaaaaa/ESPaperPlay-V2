# ESPaperPlay v2 硬件设计基线

状态：已完成[r10制造整改](pcb-dfm-r10.md)，160×110mm、236个电气位置加4个机械孔，已完成布线、双内层铺地与原理图一致性核对，0未连接；尚未上电。十一页原理图为[r6模块化绘图](schematic-layout-r6.md)，电气沿用[r5充电与温控](charging-design-r5.md)，774个逻辑引脚保持，ERC为0违规。NTC仍为用户授权的Honeywell曲线假设。更新日期：2026-11-14。

[r10](pcb-dfm-r10.md)已整改64个近焊盘孔、明确11个热孔填平盖帽并补齐官方名义阻抗窗口；203位回流、27位手焊方案保持。当前文件进入板厂生产稿确认与首板准备阶段，尚未下单。r9报告保留历史。

用户已经确定复用现有 7.5 英寸屏幕，重做主板；保持 ESP32-S3-WROOM-1-N16R8，暂不增加蓝牙耳机支持。本目录把这些约束转成可用于画原理图和验证样机的设计输入。

## 第一块 PCB：开发验证板

先设计一块与最终架构等价、便于测量的开发验证板，再收紧为产品尺寸。它仍使用 N16R8 和现有屏幕，不为测试引入更大的主控或额外内存，以免掩盖资源限制。

- 留出探针与夹具空间，不受最终外壳厚度和按键排布约束；天线、功放、麦克风、开关电源的实际布局约束仍需遵守。
- 每个外设域设置可断开的连接/测流位置，允许分别验证默认状态、上电浪涌、关断漏电和信号倒灌。
- 电池、USB、SYS、主 3.3 V、各外设轨、EN/BOOT、I²C、EPD BUSY、SD 和 I²S 关键节点有标注清楚的测试点；高速支路避免过长测试引出造成信号完整性问题。
- 电源与音频元件周围预留调试替换位置，输入、主稳压和音频支路可独立检查；测试跳线不能让正常使用时绕过电池保护或短接两个电源。
- 验证 USB 插拔与充电运行、低电量瞬态、唤醒与掉电隔离、扩展器复位/总线恢复，以及 SD/音频/Wi-Fi/EPD 并发，再冻结紧凑主板布局。

在验证板前，可以用器件评估板或模块先测充电、稳压与负载开关，这是缩小选型风险的台架工作；模块连线测试不能代替最终 PCB 的功耗、信号完整性与噪声验收。当前交付范围是本地设计文档和固件工程，不包含下单、采购或 PCB 制造。

屏幕/触摸纯延长链按原厂文档作为设计输入；接触面、方向和尺寸按图纸安排，H01做常规装配检查。供电、触摸选址时序和刷新行为在样机验证。旧版 `docs/storage.md` 的引脚表不能覆盖较新的板级配置。新板候选引脚不应复制进旧板固件，也不能据本目录直接生成生产文件。

硬件发布条件是原理图/ERC、PCB/DRC、GPIO/启动状态核对、器件规格与供货核对、样机电源和功能验证都完成。软件构建通过仅证明固件可以编译，不证明新板已经工作。
