# J501 原生封装与 NPTH 制造审查

2026-11-16，只读审查与离线项目副本修正；未调用实时 API，未导入 KiCad 库。

结论：不能把全部 Slot Region 规则降到 0.15 mm。J501 当前 0.145/0.182 mm 的 NPTH 到铜间距确实过小；其余 0.238 mm 仅违反本项目 0.30 mm 余量。完整修正文件为 `../pcb-work/footprints/J501-fixed.efoo`，它保留原生 20 个 PAD 的 ID 和编号，以及两个原有 NPTH。仅恢复 GCT 矩形推荐焊盘时，最小间距仍只有 0.175 mm，因此该副本在六个靠孔逻辑焊盘的 heel 加了圆弧避让，名义间距 0.310 mm。相应钢网开口同步避让；这是项目制造调整，并非声称厂家原图就是该形状。

## 原厂与制造依据

- 选型记录确认制造商 GCT、型号 USB4105-GF-A、商城 C3020560。原生关联封装 UUID `01ee3b6ca8bc4e04ae8b5b011ea32728`，名称 `TYPE-C-SMD_SBC-160S1A-20-S412`。名称差异本身不能证明不兼容，以下以实测原生几何和原厂图核对。
- [GCT 产品页](https://gct.co/connector/usb4105)及其[原厂图下载](https://gct.co/download?name=USB4105.pdf&type=PDFDrawing)。本次目视核对本仓库存档 B4、18/12/2023 图第一页；PDF 的 SHA256 在 JSON 报告中。尺寸均为器件面视图，推荐落盘标注公差 ±0.05 mm。
- [嘉立创国际站 FR4 制造能力](https://jlcpcb.com/capabilities/pcb-capabilities)列明 NPTH 到走线至少 0.20 mm，并说明无铜孔周边会去除 0.20 mm 铜以附着封孔膜。[官方 NPTH 指南](https://jlcpcb.com/blog/npth-design-guide)对周边铜给出 0.2–0.3 mm 的距离建议。因此不采用 0.15 mm；本项目 J501 保持既有 0.30 mm 规则。
- [嘉立创国内站能力表](https://www.jlc.com/portal/vtechnology.html)的 FR4 部分列 NPTH 孔径公差 ±0.1 mm、无铜孔周边去铜 0.2 mm。该页后部“NPTH 到线路、焊盘、铜皮 ≥0.20 mm”的明确行属于 **FPC**，本报告不将其误引为 FR4 表项。没有以规则值保证实物最坏公差；实际样品配合仍需检查。

四个宽 land 仍由相邻的同网络逻辑 PAD 组成，保持 A1/B12、A4/B9、B4/A9、B1/A12 配对；其余 A/B 信号编号和四个 shell 的 1/2/3/4 不变。对 NPTH 不缩径、不过度放大、不增添镀铜；修正原有中心回到厂家标称。

圆弧切除边界以相应 NPTH 中心为圆心，半径 0.325+0.310=0.635 mm。受影响 A1、B12、A4、A9、B1、A12 保留的铜面积分别约 99.325%、90.616%、96.455%、96.455%、90.616%、99.325%；没有移动触点横向中心或削减 toe。直接 ARC 回读离线离散验证最小间距 0.309999 mm，差值来自小于 0.25° 的离散弦。

阻焊单边扩展 0.025 mm；16 个逻辑 SMT pad 禁用自动锡膏，12 个物理 SMT land 保留显式锡膏，并使用同样圆弧避孔。四个 shell PTH 禁自动锡膏并删除对应四块显式锡膏，按既定接口固定脚手焊流程处理。

## 板边位置与重放

当前 180° 的 J501 原点为 (17.49980752, −4.60782416) mm。GCT 推荐前缘在当前板边 y=0 外约 0.365298 mm；这可表现为接口外伸，不是单凭外伸便断言电气错误。若按原厂推荐 PCB 边对齐，目标原点为 (17.49980752, −4.973122) mm，即向板内移 0.36529784 mm，转角仍为 180°。API mil 坐标为 `(688.9688, -195.792204724409, 180)`。

重放脚本 `../pcb-work/footprints/fix_j501_gct.py` 只读 `J501-before.efoo`，写 `J501-fixed.efoo`、`j501-gct-fix-report.json` 和 `J501-fixed-preview.png`。修改 42 个原生对象、删除 4 个 shell 锡膏对象、无新增对象。非制造用原生接触区图形和 3D 元数据保留；不能将这些示意图或未验证的 SBC 名称模型作为实物机械精度证据。

应用后还须核对原生网表、两孔 Ø0.65 NPTH / 四槽 PTH 的实际 Excellon、孔到铜距、12 个 SMT 锡膏开口、0 个 shell 锡膏、板边与邻件间距。组件移动应同时更新布局记录。自行装配时检查采购批次与图纸、定位柱插入、shell 脚浸润以及避孔处 heel 焊接；本次离线几何检查不替代装配试验。

## U803 规则处理

U803 的 PUI 推荐连续焊环内半径 0.525 mm，真实 Ø0.60 声孔给出名义间距 0.225 mm。最终 Gerber 已独立确认连续铜环、连续 mask、四段 paste 和单个 NPTH。建议仅为 **U803 的 pad 4 到该声孔**设置有制造来源的 0.20 mm 约束，并保留其余 Slot Region 0.30 mm；这是明确的局部制造规则，不应隐藏或忽略 DRC 错误。若软件无法表达局部规则，应保留待解决状态，由主线程选择可审计的规则机制，不能悄悄豁免。
