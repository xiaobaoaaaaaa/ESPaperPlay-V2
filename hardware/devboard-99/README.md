# ESPaperPlay 99 mm 开发验证板

**r14：99 × 99 mm、四层、顶面装配；已完成PCB布线与CAD复核。原生DRC 0违规、0未连接、0原理图一致性问题。**

用 KiCad 10 打开本目录的 [ESPaperPlay_99.kicad_pro](ESPaperPlay_99.kicad_pro)，再打开同名PCB，即本次完整走线版。包含独立根原理图、10张子页、本地符号/封装库和规则文件。

保留240个封装、236个电气器件、774个逻辑引脚和181个网络。全部器件仍在顶面，五个按键及全部调试/测流接口、21个操作包络保留。原理图、器件位置、焊盘几何、引脚分配与DNP状态保持r13；原r10和嘉立创迁移工程未修改。

已按确认流程在嘉立创EDA使用既有库建立独立原生工程。2026-11-16 已完成 12 页原理图以及 236 个器件的原生 PCB 布局、关键封装整改和局部 CAM 复核。原理图 DRC 0 错误；PCB 主信号布线、完整 GND 平面与丝印整理尚未完成。1.6 mm 参考叠层未能在当前客户端持久保存，仍待闭合；不能用于投板。详见 [原生工程检查点](easyeda-native/README.md)。未上传工厂或下单；旧 r10 制板和钢网包不能用于本 99 mm 版。
