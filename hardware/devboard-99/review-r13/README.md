# r13：U101 普通热通孔与圆弧钢网开口复核

日期：2026-11-15。对象：`../ESPaperPlay_99.kicad_pcb`，99 × 99 mm 四层开发板。**这是未布线工程的局部设计审查，不是制造包或下单放行。**

## 已实施的修改

- U101 BQ24074 增加四个真实镀铜通孔，孔径 / 铜盘直径 **0.30 / 0.60 mm**；局部中心为 `(±0.63, ±0.63) mm`。四孔均为封装内的 pad17，与 EP17 共用 GND，不是仅画在 Dwgs.User 的圆圈，也不是额外原理图引脚。
- EP17 保持 **1.68 × 1.68 mm**。EP 和四孔设置为实心连接，后续应直接连接接地平面，不通过细热焊盘辐条。当前尚无地平面或走线，不能视为已经完成散热和地回流设计。
- 四孔正反面开窗，不要求油墨塞孔、树脂填孔或电镀盖帽。孔的独立阻焊扩张为 **+0.020 mm**，外圈引脚仍为 +0.050 mm；名义最小阻焊桥约 **0.1024 mm**。
- 原 1.55 mm 整方形印膏窗改为 **1.55 mm 外框、四角圆弧避孔的单一连通开口**，配 **0.10 mm 钢网**。名义面积 1.438535 mm²，约为 EP 的 **50.97%**，面积比约 **2.485**。圆弧禁区使用保守外包折线，不通过离散化缩小避孔距离。
- PCB 和项目内封装同步修改；删除 U101 的八个旧预留圆。其余八处热孔预留、21 处操作空间标注及全部器件位置保持。表面处理参考改为 **OSP**，PCB 标题和修订字样更新为 r13 / 99 mm。
- 电路、充电设定约 0.701 A、R108 DNP / J105 开放的默认禁充状态保持。`.kicad_pro` 中用户已有的工程名称修正原样保留。

原先的十字窗只验证了名义尺寸和手工偏移；加入钻孔和钢网公差后不足以避孔。因此本次连同孔位、局部阻焊和开口形状一起修订，未直接沿用该十字窗。

## 公差结论与实际验收条件

下表是设计分析包络，**不是已经测得的首板能力，也不是嘉立创对本订单的全部承诺**。用户已确认有放大设备，可精细对位和检查；设备存在并不证明每次印刷达到指定精度。

| 项目 | 分析 / 验收条件 |
|---|---|
| U101 局部印刷对位 | X、Y 各不超过 ±0.030 mm，含相对旋转在 U101 局部产生的位移 |
| 钢网开口边缘偏差 | 向外偏差 ≤0.020 mm；向内偏差也检查，不能用标称切割精度代替来料验收 |
| 最大成品热孔 | 分析用 0.430 mm，即按名义 0.30 + 0.13 的保守情景 |
| 孔位置 | 分析用每轴 ±0.075 mm；官方未明确是径向还是每轴，此处取保守解释 |
| 叠加后的孔口距离 | 在上述包络内，印膏边缘到孔口仍保留约 0.020 mm |
| 印膏落在 EP 内 | 计入对位和开口向外误差后，外框距 EP 边仍保留 0.015 mm |

**判定：名义设计及给定包络下的印膏避孔可通过；完整制造与装配公差仍是有条件状态。** 原 ±0.10 mm 手工偏移假设不适用于本开口；钢网边缘若只能控制到 ±0.05 mm，也不能沿用本次通过结论。钢网厂不得自动将此开口改回整窗、按普通散热盘扩大或合并；若有 CAM 改动，需重算。

名义 50.97% 不是成品覆盖率下限：开口边缘全面内缩 0.020 mm 时，面积约为 EP 的 **46.94%**；向外扩张同量时约 **55.12%**。这里没有计入锡膏转移率、塌落、回流吸锡和焊接空洞，不能据几何检查保证焊接质量或温升。

还需保留两个明确的制造边界：

1. 名义环宽为 0.150 mm。若将最大孔径与每轴孔位偏差全部视作相对同层铜独立最坏误差，圆形铜盘会出现负环宽的压力情景。公开孔位公差没有明确这种独立关系，国内资料也区分导通过孔与插装孔补偿。因此不能声称实际必然破环，也不能声称完整环宽公差已经闭合；须按导通过孔确认工厂验收标准，并检查生产稿和实物。这里的四孔用于导通散热，不用于插装器件。
2. 0.1024 mm 是名义阻焊桥。国内旧指引建议单边扩张 0.05 mm，较新 LDI 资料允许 1:1 开窗，但未获得本订单的阻焊对位定量承诺。需保留本设计局部 +0.020 mm 开窗，并核对工厂 CAM 不将其自动扩大；不能把名义桥宽通过当作阻焊制造公差全通过。

首板每次印刷后，在放大设备下量化核对 U101 局部偏移、孔口和外圈引脚，不能只看“居中”。超出包络时清洗重印，不靠回流自对准弥补锡膏误印。焊接后分阶段验证充电与系统同时工作的温升及电流；热孔未填充仍可能吸锡。首板热验证完成前，不能宣称与填平盖帽的焊接良率或散热性能等效。

## 文件与复现

- [实际导出局部图](U101-actual-CAM-review.png)：铜层、正面阻焊和锡膏开口，孔来自真实 Excellon 导出。
- `u101-process.json`：实际开口顶点、参数、条件与保守压力情景。
- `change-record.json`：修改前后 PCB / 本地库 hash，以及删除的旧预留图元 UUID。
- `independent-validation.json`、原生 DRC / ERC、实际 Gerber / Excellon：由独立检查器产生；仅用于本阶段复核。
- `manufacturing-status.json`：明确区分 CAD 已验证与制造/装配验收待完成的状态，并记录正式源文件 hash。
- `tolerance-source-review.md`：原厂 / 板厂来源及未采用方案的计算依据。推荐参数以本 README 和 `u101-process.json` 的最终方案为准。

检查结果：独立检查 **39 项通过、0 错误，保留 5 项制造/装配条件提示**。原生 **DRC 0 违规、0 原理图一致性问题；ERC 0 违规**。未连线仍为 **499**。240 个封装、774 个逻辑引脚和 181 个网络保持；239 个非 U101 封装逐对象一致。实际导出四孔和开口与原生 PCB / 本地库相符，所有实孔最小孔径 0.30 mm。连续偏移包络的最小避孔间隙为 **0.0200013 mm**，实际导出名义阻焊桥为 **0.102399 mm**，热孔铜环到异网铜为 **0.172419 mm**。复现命令见 [工具说明](../tools/README.md)。

后续布线、铺铜会改变散热、回流及连通性，需要重新复核。r10 制造包及 r12 布局报告均保留为历史证据，不能作为 r13 的制造文件。
