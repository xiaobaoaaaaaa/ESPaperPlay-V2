# r7 PCB 外设布局输入（只读电气分析）

日期：2026-11-06。基于当前 r6 XML 网表及已归档原厂资料。本文未改电路、封装或正式工程。以下相邻关系/朝向用于布局；距离预算如给出，仅是本项目布线便利目标，不是原厂硬性指标。

## EPD：接口、升压、缓冲分开但紧邻

- J601 未旋转封装：焊盘排 y=0，pin1 在 x=-5.75，pin24 在 x=+5.75；塑壳伸向 +y，外插方向也是 +y。适合底边开口朝外；若在另一边则整体旋转，不镜像针序。庭院 x±9、y=-1.4…6.8mm，锁扣/排线方向另外留操作空间，不在此处放高件。
- 推荐围绕 J601 留约 45×30mm 功能区域：数字缓冲向 MCU，升压在 pin2/3 一侧，面板储能电容在各自高压针脚附近。避免把升压 SW 岛夹在 USB、I²S 或敏感测温通道之间。
- 输入高 di/dt 回路：C603 → L601 → Q601 → R602 → C603 地。把 C603 紧靠 L601.1 的供电侧，L601.2 与 Q601.3 紧邻，Q601.2 与 R602.1 紧邻；R602.2 地回流不要绕远。L601/Q601/C603/R602 同面优先。
- 高频 SW 共网：L601.2/Q601.3/D603.2/C602.2。其铜面积应小，尽量短，不在其下或旁边走 RESE、GDR、数据或模拟测量线。
- 正电压支路：D603.1 → C604.1 → J601.21；C604 地回到本地功率地。D603 尽量靠 SW 和 C604。
- 负压电荷泵：C602.1 = EPD_FLY = D601.1/D602.2；D602.1=GND；D601.2 → C609.1 → J601.23。C602/D601/D602/C609 紧凑成组。
- R602 采样：J601.3(RESE) 从 R602.1 的焊盘单独 Kelvin 引出；不能从长的 Q601 源极电流走线上取样。Q601.1(GDR) 经短线到 J601.2，R601 下拉靠 Q601。
- 面板储能/局部去耦对应关系：C601→J601.5；C605→15/16；C606→18（独立 VDD_INT，不能接3V3）；C607→20；C604→21；C608→22；C609→23；C610→24。各地端就近落地，避开 SW 岛。
- U601 输入侧朝 MCU，输出侧朝 J601；R603…R607 33Ω 紧贴 U601 各自 Y 输出端，而不是排线末端。C611 紧邻 U601.20/GND。
- U602 返回 BUSY 缓冲靠接口与返回线走廊；C612 紧邻 U602 电源，R614 靠输入。RST 下拉 R613 在屏幕端，输入默认 R608…R612 靠 U601 输入侧。
- 原厂证据：hardware/reference/good-display/GDEY075T7-T01.pdf p38（参考电路，现有渲染 build/devboard-r2-authoring/epd/reference-p38.png）。SW 回路最小化/Kelvin 是依据该拓扑的布局推导，不声称厂家给出了这块主板的精确坐标。

## microSD：插口朝板外，ESD靠接口

- J701 原生封装未旋转时：接触焊盘排在 y≈-7.725mm，卡口朝 +y；应放底边或旋转后放其他边。当前原厂图是 push-push（原库 descr 的 push-pull 错误，不作为机构依据）。
- 原厂尺寸从后端计：过压位置16.75、锁定17.55、弹出21.55mm；壳体总深约16.15mm。因此卡弹出时可比前缘多出约5.4mm，还需手指空间。不要用庭院代替外部退卡区。建议板外预留至少8mm无遮挡取卡区（项目操作空间目标）。
- 原生封装已有五块 F.Cu 禁布区，完整保留；无关铜/走线不能穿其表面接触机构。不能为了铺地删除。
- U702：保护 CLK/CMD；U703：DAT0/DAT1；U704：DAT2/DAT3；U705：机械检测及SD_3V3。应先经过靠卡口的 ESD 焊盘再进板，地端短而直接落地，避免长支线。
- C701 100n + C702 10u 紧邻 J701.4(VDD)与.6(VSS)；R701…R705 为卡侧上拉，靠接口/TMUX卡侧。
- U701/U706 位于 MCU 与卡之间，数据行径顺直，C703→U701.14，C705→U706.14。
- R710 22Ω 是 MCU 输出侧串阻：U301.31→R710→U701.2→J701.5，优先靠 U301.31；R711…R715 为0Ω串联预留，可位于 TMUX MCU侧，但避免长支线。CLK优先保证连续参考地；四层以完整In1 GND作参考。
- C704/R708 机械卡检测 RC 靠检测返回链即可，避免占高速线直接走廊。R708.2/U705.1→J701.9；.10接GND。
- 原厂证据：hardware/reference/closure-r4/files/mechanical/hirose-dm3at-2016mirror.pdf（已归档旧版原厂图）；build/closure-r4/mechanical/hirose-1.png 和 hirose-layout.png。本次已目视核实卡口方向。

## 音频：功率输出靠扬声器端，麦克风远离开关区

- U802 MAX98357A：C802(100n)紧邻 VDD7/8 与GND，C803(10u)紧接其旁；不能只靠远处 C415。EP17 是接地散热焊盘，要有完整地与后续散热过孔空间。
- U802 OUTP9→R811→J801.1，OUTN10→R812→J801.2。R811/R812 靠功放，J801靠同一板边，输出成对短粗走线。两根都是BTL开关输出，任何一根都不能接地。远离麦克风声孔/NTC/I²C区域，降低与其并行长度。
- J801 端子外插面朝板外，顶部留螺丝刀空间。端子8.5mm高，不能挡其他接口/把排线夹在其下。工程用外接8Ω扬声器，不在板上硬塞腔体轮廓。
- U801 的输出电阻 R808/R809/R810 靠对应缓冲输出端；C801紧邻U801 VCC14。U805/C806紧靠U801 OE链。R806/R805靠U802 SD_MODE输入。
- U803 是底进声：未旋转时声孔位于局部(0,+1mm)，Ø0.60mm NPTH（不是金属孔）。板下对应开口必须可通气，不能被支柱、电池/胶、铜箔或其他器件堵住。
- U803 已含半径0.5mm的全部铜层声孔禁布（铜箔、线、过孔禁入，封装自身环形地焊盘允许），保留；安装地环外径1.65/内径1.05mm不可破坏。C804 100n/C805 1u 靠VDD3和GND4。
- 麦克风放安静板边，远离L601、主稳压电感和U802输出；不必挨着功放，I²S时钟/数据以完整GND参考引到它。U804返回缓冲/C808靠麦克风输出，R813靠其输入。
- 原厂证据：MAX98357A 数据手册 p33 Layout and Grounding / Power-Supply Input（本地 build/devboard-r2-review/max98357a.txt:1840–1866）；PUI DMM-4026-B-I2S-R规格 p6/7 与已审查本地封装。最终声道/钢网/清洗及实际音频波形属于装配与上板验收。
