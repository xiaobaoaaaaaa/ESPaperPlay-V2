Reproducible scripts for archiving
  compare_repaired_inner.py:
    --board ORIGINAL.kicad_pcb --source-dir ORIGINAL_KICAD_CAM
    --previous-eda-dir PRE_REPAIR_EDA_CAM --eda-dir FINAL_EDA_CAM
    --cache REGENERABLE_CACHE --output final-inner-comparison.json
    This script includes the Gerber polygon parser, rebuilds drill/slot solids
    from the original board and regenerates all source/previous/final WKB files.
    No existing WKB file or absolute project checkout path is required.
  audit_drills_outline.py:
    --eda FINAL_GERBER.zip --kicad-zip ORIGINAL_KICAD_CAM.zip
    --board ORIGINAL.kicad_pcb --pcb-source FINAL_PCB_SOURCE.txt
    --fill-csv thermal-via-fill-spec.csv --output final-drills-outline-audit.json
  audit_inner_repairs.py:
    --source-footprints PRE_REPAIR_FOOTPRINTS.json
    --current-footprints FINAL_FOOTPRINTS.json --pcb-source FINAL_PCB_SOURCE.txt
    --thermal-requests thermal-repair-requests.json
    --pour-requests pour-neck-repair-requests.json
    --comparison-report final-inner-comparison.json
    --witnesses narrow-neck-witnesses.json --output final-inner-closure.json
    Run the comparator first; this closure audit consumes its newly generated
    geometry companions and imports the neighboring comparator module.
  Environment: system pcbnew, gerbonara1.6.3, shapely2.2.0. Versions are recorded
  by the comparator. Cache is optional and SHA-256 keyed.
