# 自行回流钢网候选 — REVIEW ONLY

仅使用 `ESPaperPlay_Devboard-DIY-F_Paste.gtp`；正面印膏，无背面钢网。采用与裸板CAM相同的绝对原点/mm坐标。夹具、钢网边框与定位标识由实际手印工装另定，文件未包含实体夹具。勿按预览图缩放加工。

候选厚度 **0.10mm**，需结合实际锡膏和工装试印；这是全板工程折中，不是每个芯片原厂都推荐0.10mm。U803麦克风环形开孔分成四段，候选钢桥宽 **0.15mm**，消除无支撑中心钢岛；桥宽并非PUI规定值，需要钢网厂确认加工并在首板检查声学密封。

203个器件、636个独立膏口。本版：

- C501/C502/J301/J302/J303/R108不装、不印膏。
- J406/J501/J601/J701及所有通孔器件回流后手焊，不印膏；包括USB四个固定槽焊盘。
- U301实装：40个外围焊脚印膏，9个中心EPAD窗口取消；中心EPAD不焊为Espressif允许的选项，热性能仍待测。
- U101/U201/U203/U802等其他IC的功率地/散热焊盘保留膏口。11个焊区内过孔中10个与膏口相交，必须和制板孔处理一起审核；本文件没有自动消除其吸锡风险。

正式r8 PCB铜、阻焊、孔、布线与网络保持不变；只是单独派生印膏图。原始r8 F.Paste不可替代此文件。最小几何面积比约0.8898（0.10mm厚），只通过几何筛查，不证明实际脱模、润湿或空洞合格。

先确认钢网加工与孔处理，再制作首板并检查印膏偏移、桥连、缺膏、隐藏焊点与麦克风声孔/声密封。具体原厂依据、几何数据及源文件不变断言见整套审查记录的stencil-review.md和stencil-audit.json。
