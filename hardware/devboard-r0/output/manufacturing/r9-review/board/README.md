# 裸板CAM — REVIEW ONLY

源板r8；制造审查r9。160×110mm、四层FR4、名义1.6mm、外1oz/内0.5oz，拟指定JLC04161H-7628、绿色阻焊、ENIG。层序：F.Cu / In1.Cu(GND) / In2.Cu(GND) / B.Cu。普通锣边，板框取Edge.Cuts线中心。

- `.gtl/.g1/.g2/.gbl`：四层铜；`.gts/.gbs`：阻焊；`.gto/.gbo`：丝印；`.gm1`：板框。
- PTH.drl：656个镀孔，含549个native过孔、12个U301模块热孔、95个普通组件孔（其中4个USB槽）。NPTH.drl：7个非镀孔，含4个安装孔、2个USB定位孔、1个麦克风声孔。
- 单位mm，绝对原点；Gerber/Excellon同原点。槽用Excellon route格式。SVG钻孔图仅供查看，按DRL加工；未使用G85 alternate槽输出以兼容本次回读器。
- 不含F.Paste/B.Paste；独立DIY钢网见相邻stencil目录，不用原始r8默认paste。

尚需工厂确认实际层叠/铜截面下USB 90Ω±10%和SD 50Ω±10%，并复核阻焊开窗及焊盘邻孔处理。当前USB主线W/S=.26/.15mm、SD主线W=.35mm；F.Cu参考In1，B.Cu参考In2。job中的阻抗控制标记只是设计要求。

11个IC焊区内孔：U101×4、U201×2、U203×1、U802×4，不能仅靠tented标记认定不吸锡。U301中心12孔单独处理：本次钢网不印中心EPAD，保留40外围焊脚。普通95个组件孔和7个NPTH不能按“所有孔填孔”封堵，尤其Ø0.60mm麦克风声孔必须畅通。具体坐标/开窗审查在整套review-r9记录中。

多数SMT焊盘设计阻焊扩展为0，局部例外为U101/U201 +.05mm、U803 +.025mm；不可未经细桥复核统一扩大。工厂应明确实际开窗补偿和对位能力，再提交可审查生产稿。本目录文件尚未制造放行。

另有44个过孔的铜环触及SMT焊盘，实际孔口名义盖住，但最小孔边到阻焊开口余量仅0.00498mm；需要明确填孔/盖帽或局部移孔方案后再放行，不能直接按普通可靠盖油接受。裸板ZIP另附special-hole-register.csv，记录67孔的UUID、KiCad绝对坐标（Y向下）与实际开窗数据；不得把该坐标直接当作Gerber的负Y，也不得将待审核清单自动当作已选定填孔指令。
