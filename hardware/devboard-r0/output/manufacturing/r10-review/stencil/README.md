# r10 自行回流钢网候选 — REVIEW ONLY

只使用 `ESPaperPlay_Devboard-DIY-F_Paste.gtp`，正面203位、636个开孔；没有背面工序。与裸板CAM相同原点/mm坐标，无钢网边框或夹具尺寸，勿按预览缩放加工。

候选厚度0.10mm，麦克风U803环形开孔用四条0.15mm钢桥支撑中心。桥宽和全板厚度是工程选择，需加工能力确认及首板试印/回流/声密封检查，不是所有器件原厂统一推荐值。

- DNP：C501/C502/J301/J302/J303/R108不装、不印膏。
- J406/J501/J601/J701及所有通孔位置后手焊，不印膏，包括USB固定槽焊盘。
- U301实装，印外围40脚，中央EPAD不印膏；模块温升另测。
- U101/U201/U203/U802的热/地焊盘及分窗保留。其11个焊区孔必须按裸板附表树脂填平、电镀盖帽，不能仅靠这份钢网避免吸锡。

原始默认F.Paste仍有DNP/手焊接口、模块中央和麦克风无支撑环形开孔，不能替代此文件。本钢网派生过程保持r10铜、孔、阻焊和网络不变；最小面积比约0.8898（0.10mm厚）仅为几何筛查。不要擅自统一扩缩膏口；保持声孔畅通，按实际锡膏/器件要求验证印膏和回流。
